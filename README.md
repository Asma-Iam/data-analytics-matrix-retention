# Customer Retention & Cohort Analysis — Greenweez

> Le Wagon Data Analytics bootcamp (2026)

## Business question
How did COVID-19 impact customer acquisition and retention for an organic e-commerce retailer?

## Data
Order history of Greenweez customers, queried from **Google BigQuery**.

## Approach
1. Turnover analysis (yearly and monthly)
2. Customer base analysis: new customers over time
3. **Cohort analysis** by first-order month
4. **Retention matrix** visualised as an interactive Plotly heatmap

## Stack
Python · pandas · Plotly · Google BigQuery · Jupyter
